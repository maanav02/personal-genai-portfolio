# Personal Generative AI Portfolio

A responsive static portfolio built with HTML5 and CSS3. It documents AI tools explored, prompt-engineering experiments, practical learning activities, and output verification.

## Files

- `index.html` — portfolio page and evidence gallery
- `style.css` — responsive dark-theme styling
- `*.webp` — 14 compressed screenshots used in the evidence gallery (stored in the repository root)

## Run locally

1. Open this repository in Visual Studio Code.
2. Open `index.html` in a browser, or use the VS Code Live Server extension.

The site is static and does not require JavaScript, a backend, a package manager, or an external font service. Keep `index.html`, `style.css`, and the WebP screenshots together in the repository root.

## Evidence included

- **Activity 01 — AI fundamentals:** ChatGPT and Gemini screenshots.
- **Activity 02 — Prompt engineering:** zero-shot, one-shot, few-shot, role-based, and contextual/iterative examples from ChatGPT and Gemini. The one-shot screenshot is from Gemini.
- **Activity 03 — HTTPS research:** Perplexity research and screenshots of MDN TLS documentation and CISA website-security guidance.

The gallery screenshots are records of the sessions. They do not independently validate every statement shown in an AI response; consult the linked primary sources for technical verification.

## Tools documented

- ChatGPT — AI concept explanations and prompt-engineering experiments.
- Google Gemini — alternative explanations and prompt-response comparisons.
- Perplexity — research on HTTPS/TLS and source discovery.
- Canva — optional only; not counted as explored or completed.

## Publish with GitHub Pages

1. Open the repository on GitHub.
2. Select **Settings** → **Pages**.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then select **Save**.
5. Wait for GitHub Pages to finish publishing. The expected site address is:
   `https://maanav02.github.io/personal-genai-portfolio/`

The site address becomes usable after Pages is enabled and the deployment completes.
