# Personal Generative AI Portfolio — Evidence Updated

A responsive static portfolio built with HTML5 and CSS3. This edition adds a curated evidence gallery containing 14 supplied screenshots from the documented project activities.

## Files
- `index.html` — portfolio page, including the evidence gallery
- `style.css` — responsive dark-theme styling
- `assets/evidence/` — 14 compressed WebP screenshots grouped by project activity

## Run locally
1. Extract the ZIP while preserving the folder structure.
2. Open the extracted folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

The site is static and does not require JavaScript, a backend, a package manager, or an external font service. Keep `index.html`, `style.css`, and the `assets` folder together.

## Evidence included
- **Activity 01 — AI fundamentals:** ChatGPT and Gemini screenshots.
- **Activity 02 — Prompt engineering:** zero-shot, one-shot, few-shot, role-based, and contextual/iterative examples from ChatGPT and Gemini. The one-shot screenshot is from Gemini.
- **Activity 03 — HTTPS research:** Perplexity research and screenshots of the MDN TLS documentation and CISA website-security guidance.

The gallery screenshots are static records of the sessions. They do not independently validate every statement shown in an AI response; consult the linked primary sources for technical verification.

## Tools documented
- ChatGPT — AI concept explanations and prompt-engineering experiments.
- Google Gemini — alternative explanations and prompt-response comparisons.
- Perplexity — research on HTTPS/TLS and source discovery.
- Canva — optional only; not counted as explored or completed.

## Customisation
- Edit the displayed author name in `index.html` if required.
- Edit colours in the `:root` block at the top of `style.css`.
- Add new screenshots to `assets/evidence/` and create matching evidence cards in the `#evidence` section.
